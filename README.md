# Gerador de Senhas

Gerador de senhas aleatórias feito com HTML, CSS e JavaScript. O usuário escolhe o tamanho e se quer números e símbolos, e a senha é gerada na hora.

🔗 **Link com Erro -EM PROCESSO-** https://isabelleassis74.github.io/gerador-de-senhas

## Tecnologias
- HTML
- CSS
- JavaScript

## Funcionalidades
- Escolha do tamanho da senha (de 4 a 32 caracteres)
- Opção de incluir números e símbolos
- Botão para copiar a senha
- Aviso quando o tamanho é inválido
- Layout que se adapta ao celular

## Como rodar
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

## O que aprendi
- Usar laços de repetição (`for`) e números aleatórios em JavaScript
- Trabalhar com checkbox e campos de formulário
- Copiar texto para a área de transferência
